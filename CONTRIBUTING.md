# Contributing

Thank you for your interest in DCFP. The project is at an early foundation stage; interfaces and folder structures may change.

## Before contributing

- Discuss substantial changes through a GitHub issue first.
- Keep each methodology's equations and assumptions isolated.
- Include source references for factors, equations, and datasets.
- Add tests for calculation logic and document expected units.
- Never commit credentials, personal data, or production configuration.
- Do not copy third-party workbook content or other protected material without confirming permission.

## Pull requests

Describe the scope, affected method and version, sources, tests performed, and any limitations or deviations. A method must not be marked validated without documented evidence.
