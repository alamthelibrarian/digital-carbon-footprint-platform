# DPC v1.0 Assessment Report and Export

## Report contents

The DPC v1.0 calculator presents a readable assessment report after a successful calculation. It includes:

- Assessment title and subject.
- Organization/unit, system boundary, functional unit, reporting period, geography, assessment ID, UTC creation timestamp, and method/version.
- Native DPC total and category-level emissions.
- Category contribution percentages calculated against the native DPC total. Percentages are omitted when the total is zero.
- Factor-provenance entries captured by the result adapter, including optional source-kind classification.
- Structural factor-provenance coverage status.
- Assumptions and method limitations.
- A collapsible complete JSON calculation record.

The category chart is a presentation of the native DPC category totals. It does not recalculate or harmonise emissions.

## JSON export

Use **Download JSON record** to save the complete machine-readable record. It includes the result envelope, original input snapshot, native DPC result, metrics, factor provenance, assumptions, limitations, and traceability metadata.

The JSON record is intended for inspection, archival, and downstream processing. Treat it as an assessment record, not as evidence that the input data or factor sources have been independently verified.

## Print and PDF

Use **Print / Save as PDF** to open the browser's print dialog. Select a printer or the browser's **Save as PDF** destination when available.

The PDF is generated by the user's browser print function. DCFP does not currently generate or store PDF files on a server, and PDF layout may vary slightly by browser and operating system.

## Interpretation and validation

The calculator remains a development preview and has not been validated for formal reporting, compliance, or audited disclosure. The report prominently retains this status.

Activity-data confidence describes the confidence level entered for activity data; it is not an independent validation. It must not be interpreted as emission-factor quality.\n\nFactor-provenance coverage is a structural indicator only. It checks whether recorded factor entries contain source text; it does not establish source authority, scientific quality, accuracy, geographic or temporal suitability, or independent verification. Emission-factor quality is not independently assessed by this preview.

The DPC v1.0 calculation formulas and native aggregation remain unchanged by the report layer. The report adapter and presentation layer must not silently alter method calculations or imply comparability with other methods.

Embodied carbon is not included. Review the DPC toolkit and the method notes for the authoritative methodology, assumptions, and limitations.
