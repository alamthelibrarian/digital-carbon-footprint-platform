# DPC Carbon Footprint Toolkit v1.0 engine

**Status: planned — not implemented.**

This directory is reserved for an independent software implementation based on the DPC Carbon Footprint Toolkit v1.0. Do not add formulas or emission factors until the source workbook and publication have been systematically audited and the applicable reuse terms have been checked.

Primary reference: Digital Preservation Coalition. (2026). *Carbon Footprint Toolkit*. https://doi.org/10.7207/carbonfootprinttoolkit26-01

The implementation must preserve the source methodology's calculation logic, document any interpretation, and include regression tests. It is not an official DPC product and is not endorsed by DPC.

## Formula audit

A workbook structure and formula transcription is maintained in [FORMULA-MAP.md](./FORMULA-MAP.md). This is an implementation audit document, not a replacement for the DPC publication or workbook. The engine remains unimplemented until the formula mapping is translated into tested TypeScript functions and regression-tested against workbook outputs.
